# shumoku-next

> [!WARNING]
> 🪏 Work In Progress 🪏

このリポジトリでは [Shumoku](https://github.com/konoe-akitoshi/shumoku) v1.0.0 のリリースに向けて、全面的なリライトを行っています。v1.0.0 のリリース時に、リライト元の [konoe-akitoshi/shumoku](https://github.com/konoe-akitoshi/shumoku) をアーカイブし、このリポジトリを `shumoku` に改名する予定です。

## 使用言語

- 日本語を第1言語とする
- 英語版ドキュメントは日本語の正本から翻訳して作成する

### Issue・PR

- 日本語で書く
- 英語を母語とする人は英語で書いてもよい

### コード

- 変数名や関数名などの識別子：英語
- コメント：日本語

### コミットメッセージ

- [Conventional Commits](https://www.conventionalcommits.org/) の形式に従う
- タイトルの`:` 以降と本文は日本語で書く
- 例：`feat(layout): ポートの自動配置を追加`

## コントリビューション

- 外部からの PR は受け付けない
- バグ報告や要望は Issue で受け付ける

## 設計メモ

- [`notes/design.md`](notes/design.md)：設計判断／検討の過程で却下した案
- [`notes/open-questions.md`](notes/open-questions.md)：検討中もしくは判断を保留しているトピック
